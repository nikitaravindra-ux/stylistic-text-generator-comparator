# Stylistic Text Generator Comparator

[![Built with askThili](https://ask.thili.ai/api/v1/public/projects/fdv4g8r4n4/badge.svg)](https://ask.thili.ai/b/fdv4g8r4n4)

This project implements a 'Stylistic Text Generator Comparator' for sports journalists. It compares text generated by a LoRA-adapted Large Language Model with an N-gram model, both fine-tuned on specific sports commentary styles. The goal is to demonstrate the ability to fine-tune a pre-trained model with LoRA on a custom text style and evaluate its text generation quality against a simpler N-gram model.

## What you are building

**Goal.** You will build a system that generates sports commentary text using two different language models: an N-gram model and a LoRA-adapted LLM, both fine-tuned on a custom corpus.

**Done when.** You will have successfully fine-tuned a pre-trained LLM with LoRA on a custom text style and compared its text generation quality against an N-gram model built from the same text, providing a clear interface for this comparison.

## Run it

You need Python 3.12 and git.

```bash
python3.12 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env        # then choose a model; see the comments inside
python -m app.cli hello
pytest
```

Your work goes in `app/core.py` (one stub per milestone) and `tests/test_core.py`. The first tests pass already; they
check the plumbing.

## Settings and secrets

Model settings live in `.env`, which is ignored by git. **Never commit `.env` or paste a key into code.** If a key ever
reaches GitHub, treat it as leaked and make a new one.
